# AI 语音绘图工具

一款纯语音控制的绘图工具，用户无需鼠标或键盘，仅通过语音指令即可完成绘图创作。

## ✨ 核心特性

- 🎤 **纯语音控制** - 唤醒词"你好"激活，全程语音操作
- 🎨 **AI 智能绘图** - 描述任意场景，AI 自动生成精美图片
- 🖼️ **风格转换** - 支持油画、水彩、素描、卡通、动漫等风格
- 🔧 **完整操作控制** - 撤销、重做、清除、保存、比例切换
- 💬 **智能对话** - 支持局部修改、细节调整
- 📱 **现代化 UI** - Codex 浅色主题，响应式布局

---

## 🚀 快速开始

### 环境要求
- Node.js v14+
- Chrome 或 Edge 浏览器
- 麦克风权限

### 安装运行

**方式一：双击启动（推荐）**
```
双击 start.bat
```

**方式二：命令行启动**
```bash
# 安装依赖
npm install

# 启动服务器
node server.js

# 访问应用
http://localhost:3001
```

## 🎯 语音指令

### 唤醒与基础
| 指令 | 功能 |
|------|------|
| "你好" | 唤醒工具 |
| "画一只猫" | AI 生成图片 |
| "一幅日落海滩" | AI 生成场景 |

### 风格转换
| 指令 | 功能 |
|------|------|
| "油画风格" | 转换为油画 |
| "水彩风格" | 转换为水彩 |
| "素描风格" | 转换为素描 |
| "卡通风格" | 转换为卡通 |
| "动漫风格" | 转换为动漫 |

### 操作控制
| 指令 | 功能 |
|------|------|
| "撤销" / "恢复" | 撤销/重做 |
| "清除" | 清空画布 |
| "保存" | 保存为 PNG |
| "帮助" | 显示帮助 |
| "待机" | 进入待机状态 |

### 局部修改
| 指令 | 功能 |
|------|------|
| "把耳朵改成蓝色" | 修改特定部分 |
| "大一点" / "小一点" | 调整大小 |
| "移到左边" | 移动位置 |

## 📋 重大更新日志

### 2026-06-14

#### 🎨 UI 全面升级
- **Codex 浅色主题**：采用 `#339cff` 主色调，现代化设计
- **侧边栏布局**：左侧工具栏 + 中间画布 + 右侧历史面板
- **浮动语音指示器**：画布底部居中显示语音状态
- **顶部进度条**：图片生成时显示渐变进度条
- **字体优化**：使用 Outfit + Work Sans 字体组合

#### 🤖 AI 图像生成
- **接入 agnes.ai API**：使用 `agnes-image-2.0-flash` 模型
- **支持任意描述**：从"画一只猫"到"星空下的城堡"
- **风格转换**：支持油画、水彩、素描、卡通、动漫风格
- **局部重绘**：基于原图进行细节修改

#### 🎤 语音识别增强
- **唤醒词机制**：说"你好"激活，15秒无操作自动待机
- **回声消除**：播报时自动屏蔽语音识别，防止误识别
- **置信度过滤**：低置信度结果自动忽略
- **循环询问**：未识别指令时循环提示用户

#### 🎯 指令系统完善
- **系统指令**：撤销、重做、清除、保存、帮助、待机
- **绘图意图检测**：区分绘图指令和普通对话
- **模糊匹配**：支持相似表达（如"画个圆" = "画一个圆"）
- **多格式导出**：支持 PNG、JPG、WEBP 格式

#### 📱 交互体验优化
- **文字通知**：取消语音播报，改用文字提示框
- **画布管理**：支持新建画布、清空画布
- **历史浏览**：支持查看历史图片
- **语音确认**：重要操作需语音确认
- **语音反馈**：支持音量、语速调节

### 2026-06-13

#### 🔧 核心架构
- **Edge TTS 集成**：使用微软"晓晓"高质量语音
- **Vosk 离线识别**：支持离线语音识别（需安装 Python）
- **服务器优化**：修复 TTS 并发问题，添加超时机制

#### 🎨 绘图引擎
- **14 种图形**：圆、方、三角、星、心、箭头等
- **画框效果**：圆角、阴影、边框
- **撤销/重做**：最多 50 步历史记录

## 🏗️ 技术架构

### 前端
- **HTML5 Canvas** - 绘图引擎
- **Web Speech API** - 语音识别（Chrome/Edge）
- **Edge TTS** - 高质量语音合成
- **agnes.ai API** - AI 图像生成

### 后端
- **Node.js** - 服务器
- **MsEdge TTS** - 语音合成服务
- **agnes.ai** - AI 图像生成服务
